# Goregaon Market

This is Goregaon Mart (https://github.com/Jaydev05/corner-cart-collective.git), an e-commerce mobile/web app built on TanStack Start (React 19 + Vite + Tailwind CSS) with Lovable Cloud backend.

Please read AGENTS.md, package.json, and the codebase to understand the project structure:

1. Storefront is in src/routes and src/components/shop/.

2. Admin panel is at /admin with components in src/components/admin/.

3. All UI must stay mobile-first, responsive, and follow existing semantic design tokens and components.

4. Keep edits credit-efficient and focused strictly on the tasks requested.

5. After finishing each requested task, verify the build passes with zero errors and commit/push the changes cleanly to GitHub so they can sync back to the main repository.

Acknowledge that you have inspected the repo and are ready for instructions.

This project was built with [Lovable](https://lovable.dev).
